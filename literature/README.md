# Literature

Project literature is organized by its role in the study:

- `papers/graph_recommendation/`: graph recommendation, contrastive learning,
  heterogeneous GNN, and spectral GNN papers.
- `papers/geospatial_data/`: geographic coverage and mobility-data references.

Paper filenames are retained verbatim so references from historical notes can
be recovered. A citation database should be produced once the final article's
actual cited subset is known.
